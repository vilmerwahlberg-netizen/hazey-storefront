## Ursprung

- **Källa:** befintlig produktfri Theme 8-asset `theme8/assets/landing-thcx/product-stage-960.webp`, SHA-256 `edfdb1a4…02ce78`. Den används redan som stenstage på THCX- och Engångsvapes-landningarna.
- **Designunderlag:** `design/thcx-mall-2026-11-13/visual-redesign/ASSET-MANIFEST.md`, "atmosfäriska lager".
- **Typ:** stämningsbild ur Hazeys designunderlag, troligen syntetisk. Ursprunget bör bekräftas, se beslut i `theme8/review/thch-hhc-knowledge-2026-11/BESLUT.md`.
- **Användning:** bara illustrativ, inte dokumentär. Sidan säger det under Källor.
- **Bearbetning:**
  - speglad horisontellt, så att olivgrenen hamnar till höger där bilden inte tonas bort
  - stenhyllan nertill bortskuren, så att det inte ser ut som en produktvisning
  - brightness 1,04
  - WebP q84
